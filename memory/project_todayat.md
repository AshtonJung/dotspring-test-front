구글 킵 + 구글 캘린더를 하나로 합친 개인 일간 플래너.

**핵심 불편함**: 구글 킵으로 할일을 관리하고 구글 캘린더로 일정을 따로 관리하다보니 두 도구가 병합이 안 돼서 불편.

**해결 방향**: 구글 킵 인터페이스를 기반으로, 캘린더 일정을 카드 형태로 투두리스트 중간에 삽입.

**명령어 시스템** (todo.vue 입력창에서):
- `/일정 [내용]` → 일정 카드로 등록 (캘린더 이벤트 형태)
- `/일기 [내용]` → 하단에 일기 카드로 붙여짐
- `/여행 [도시] [시작일]부터 [종료일]까지` → 여행 일정 등록, 해당 날짜 방문 시 배경화면 자동 변경

**사용 패턴**: 매일 날짜를 제목으로 메모 한 장 추가 → 그날 할일 정리 + 체크 → 일정은 카드로 인라인 표시

**Why**: 두 앱을 오가는 컨텍스트 스위칭 없이 하나의 인터페이스에서 할일과 일정을 함께 관리

**How to apply**: 기능 추가 시 "구글 킵처럼 단순하고 빠른 입력" + "캘린더처럼 일정 시각화"를 동시에 고려. 복잡한 UI보다 명령어 기반의 빠른 입력을 우선.
